# 프로젝트명

> 2st Team Project

- 프로젝트 명 : RAG-insure-bot — 데이터 전처리와 기본 모델을 Django 기반 웹에서 검증
- 인원 : 5명
- 기간 : 2025.07.28 ~ 2025.08.28
- 언어 : Python 3.10.9
- DBMS : MySQL
- Python Library : 프로젝트 루트의 `requirements.txt` 참조
- micro Web Framework : Django
- 프로젝트 소개 : 데이터 전처리와 모델링을 수행하고, 웹 데모로 결과를 확인하는 팀 프로젝트
